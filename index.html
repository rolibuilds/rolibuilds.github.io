  4. Power Platform

    Hands-on exercises at an OTP LAB open day showed me what Power Platform could do for finance processes, so I started building my own use case: the Corporate Services Automation Platform (CSAP), below.

Corporate Services Automation Platform (CSAP)

A personal MVP for requests that need both approval and financial control: one traceable process instead of disconnected emails and spreadsheets.

Current capability

  • Financial validation
  • Multi-currency handling
  • FX-rate maintenance
  • Budget-capacity checks
  • Approval routing
  • Clarification and exception handling
  • Traceable approval history

How I used AI

  • Reviewed and trimmed the proposed MVP scope; extra features stayed out until there was a clear business need.
  • Kept testing after the first checks passed and found an implementation error that would otherwise have gone unnoticed.
  • Designed a practical unauthorised-user test and verified that the security control worked inside the automation, not only in the user interface.

Built with: Dataverse, Power Automate, Power Apps (Dataverse views). Copilot supported research, architecture, critical review and debugging. A custom UI is planned with Claude and is not built yet. Built in a personal environment with test data; controls validated through runtime tests; not tested at organisational scale.
